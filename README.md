# LINE Chrome拡張機能 アクセシビリティ改善パッチ (Accessible LINE)

このプロジェクトは、Google Chrome版のLINE拡張機能において、キーボード操作やスクリーンリーダー（音声読み上げ）での利用を困難にしている問題を一撃で修正し、アクセシビリティを劇的に向上させるためのパッチスクリプトおよびカスタム拡張機能のテンプレートです。

全盲や弱視など、スクリーンリーダーやキーボードのみで操作を行う方をはじめ、アクセシビリティを必要とするすべての人に向けて開発されています。

---

## 🌟 改善されること（機能仕様）

本パッチを適用すると、公式LINE拡張機能に以下の強力なアクセシビリティ機能が追加されます。

### 1. キーボード操作・フォーカス管理の最適化
* **フォーカスの視認性向上**：
  フォーカスがあたっている要素の周りに、LINE公式カラー（緑色 `#06c755`）の太さ `3px` のアウトラインをはっきりと表示します。
* **F6 / Shift+F6 キーによるペイン循環切り替え（Slack風）**：
  `F6` キーを押すことで、**グローバルバー（GNB） ➔ 左側リスト（トーク・友だち） ➔ 右側トークルーム ➔ グローバルバー** の順にフォーカスを素早く循環して移動させることができます。`Shift + F6` を押すと逆順に移動します。フォーカスした際には「グローバルバーにフォーカスしました」のように音声でアナウンスされ、現在の位置をすぐ把握できます。
* **完全キーボード操作対応**：
  左側メニュー（GNB：友だち、トークなど）、上部タブ（すべて、グループなど）、トーク一覧、友だち一覧、各種ボタン（新規トーク、友だち追加、オプション）、およびメッセージ入力欄やスタンプ・添付ファイル選択ボタンなどに、Tabキーで順番にフォーカスが当たるようになります。
* **Enter/Spaceでの実行**：
  通常はキーボードで操作できないカスタムボタンやリスト項目も、フォーカスを当てて `Enter` または `Space` キーを押すだけで、マウスクリックと同様に確実に実行できます。
* **エディタボタン群（ファイルを添付など）の移動向上**：
  メッセージ入力欄の下部に並ぶボタン群（スタンプ、絵文字、ファイル添付など）の間で、TabおよびShift+Tabキーによる前後の移動、および入力欄やメッセージリストへの往復が、公式のキーブロック動作をバイパスしてスムーズに行えるようになります。

### 2. トークメッセージ履歴の時系列表示と読み上げ順の修正（最重要）
* **正しい時系列順（上から下）の実現**：
  公式LINEは技術的な都合（`flex-direction: column-reverse`）により、DOM（HTMLの内部構造）上はメッセージが「新しい順（下から上）」に並んでおり、スクリーンリーダーでそのまま読むと会話の流れが逆順になってしまいます。
  本パッチは、JSとCSS両方に修正を入れることで、**DOM構造としても描画としても「上から下（過去から現在）」へ時系列順に正しく並べ替えます**。これにより、スクリーンリーダーで普通に上から下へ読むだけで、会話が時系列順に自然に頭に入ってきます。
* **スクロール位置の自動調整**：
  時系列順の変更に伴い、新しいメッセージが届いた際やトークルームを開いた際に、自動的に一番下の最新メッセージまで正しくスクロールするよう制御を修正しています。

### 3. トーク・友だちリストおよびトークルーム内の快適なキーボード移動
* **左側リスト（トーク・友だち）内の上下矢印キー移動とEnter決定**：
  トークリストや友だちリストにフォーカスがある状態で、**`ArrowUp`（上矢印）および `ArrowDown`（下矢印）キー**を押すことで、各トークルームや友だちの間をスムーズに上下移動できます。また、移動時に「ボタン」や「リンク」といった余計なコントロールタイプは発音されず、トークルームの詳細情報（相手の名前、未読数、最新メッセージ、時間）だけがスッキリと読み上げられます。目的のトークルームで **`Enter`** または **`Space`** を押すと、プロフィール画像などにフォーカスを奪われることなく、確実にそのトークルームを開くことができます。
* **`Escape` キーによるリストへのフォーカス自動復帰**：
  右側トークルーム内でやり取りをした後、**`Escape`** キーを押すと、LINE公式のトーククローズ処理の実行（120ms待機）を待って、自動的にフォーカスが左側のリスト（トーク・友だち一覧）へスマートに戻ります。フォーカスを見失う心配がありません。
* **メッセージ履歴内の矢印キー巡回**：
  メッセージリスト内のいずれかのメッセージにフォーカスがある状態で、**`ArrowUp`（上矢印）および `ArrowDown`（下矢印）キー**を押すことで、前後のメッセージへ素早くフォーカスを移動できます。
* **メッセージと入力欄のシームレスな往復**：
  * メッセージリストの一番最後のメッセージで `ArrowDown` または `Tab` キーを押すと、自動的にメッセージ入力欄（テキストエリア）にフォーカスが移動します。
  * メッセージ入力欄で **`Shift + Tab`** を押すと、メッセージリスト（直近のメッセージ）にフォーカスが戻ります。
* **メッセージリストから左サイドバーへのダイレクト戻り**：
  メッセージリスト内のいずれかのメッセージにフォーカスがある状態で **`Shift + Tab`** を押すと、トークルーム上部の各種ボタン（プロフィールや通話など）にフォーカスが捕まることなく、左サイドバー（トーク一覧や友だち一覧など）の最後の要素へ直接フォーカスが戻ります。

### 4. 音声読み上げ（スクリーンリーダー）向け最適化
* **分かりやすいメッセージ読み上げ（`aria-label` の最適化）**：
  メッセージにフォーカスが当たった際、スクリーンリーダーが「自分: こんにちは 10:30」や「山田太郎: [画像] 10:31」のように、**[送信者名]、[本文または画像・スタンプ等の種別]、[送信時間]**を整理された形で一行で読み上げます。
* **見出し（Heading）ジャンプでの爆速移動**：
  スクリーンリーダーの見出し移動機能（Hキーや、数字の1、2キーなど）を使って、読みたい場所に一瞬でジャンプできます。
  * **トークルームのタイトル（相手の名前）** ➔ 見出しレベル1 (`h1`)
  * **メッセージ履歴の日付区切りヘッダー** ➔ 見出しレベル2 (`h2`)
* **Live Region（`aria-live`）による自動読み上げ・通知**：
  * トークルームを開いた瞬間、「〇〇とのトークルームを開きました」と自動的にアナウンスします。
  * トークルームを開いている間に新着メッセージが届くと、自動的にその内容（「送信者: 本文」）をリアルタイムで読み上げます。
* **モーダルダイアログのアクセシビリティ対応**：
  設定画面や確認画面などのダイアログが開いた際、「ダイアログが開きました」「閉じました」と音声で通知します。さらに、Tabキーでのフォーカス移動がダイアログの外に出ないように制御し（フォーカストラップ）、`Escape` キーを押すことでダイアログを閉じることができます。
* **NVDA等のフォーカスモードの維持**：
  メッセージリストおよび左側リスト（トーク・友だち一覧）に `role="application"` を設定し、それらにフォーカスが移動した際、スクリーンリーダー（特にNVDA）が勝手にブラウズモードへ切り替わるのを防ぎ、矢印キーでのメッセージ巡回やリスト移動（フォーカスモード）を快適に行えるように最適化しています。

### 5. メンション機能のアクセシビリティ強化
* **メンション候補リストのキーボード移動と読み上げ**：
  メッセージ入力欄で `@` を入力した際に表示されるメンション候補（ユーザーリスト）で、上下矢印キー（`ArrowUp`/`ArrowDown`）による選択移動をサポートし、選択された相手の名前を「選択: 山田太郎」のように音声で分かりやすく読み上げます。
* **カーソル移動時のメンション個別読み上げ**：
  メッセージ入力欄の中で左右矢印キーを使って移動した際、カーソルがメンション文字列（例：`@山田太郎`）の真上（左側）に来た瞬間に、自動的に「メンション: @山田太郎」と音声でアナウンスします。
* **正確な位置判定と安定した音声通知**：
  * カーソルがメンションの右隣の文字（スペースや他の文字）に移動したときには読み上げを終了するため、カーソル位置と読み上げのズレが発生しません。
  * 同じメンションの上を連続して往復する場合でも、スクリーンリーダーが読み飛ばすことなく、毎回確実に音声を通知するよう制御されています。
* **公式アップデートに耐える文字列解析フォールバック**：
  LINE公式の内部API（`rawValue` や `_characterPool`）が変更された場合でも、自動的に標準の文字列およびカーソル位置解析による判定へ切り替わり、メンションの読み上げ機能が失われないよう頑健化（ロバストネス向上）されています。

## 🛠️ 前提条件
実行するパソコンに **Node.js** がインストールされている必要があります。
インストールされていない場合は、[Node.js 公式サイト](https://nodejs.org/) からLTS（推奨版）をダウンロードしてインストールしてください。

## 🚀 使い方（簡単4ステップ）

### ステップ 1：このパッチプロジェクトをダウンロードする
1. このページの右上にある「**Code**」ボタン（スクリーンリーダーでは「Codeメニューボタン」）を選択します。
2. メニューから「**Download ZIP**」を選択してZIPファイルをダウンロードします。
3. ダウンロードした ZIP ファイルを、パソコンの使いやすい場所（「ドキュメント」や「デスクトップ」など）に解凍（展開）します。

### ステップ 2：公式LINE拡張機能のインストール先パスを確認する
Google Chromeにインストールされている、公式のLINE拡張機能のフォルダパスを特定してコピーします。
通常, Windows環境では以下の場所にインストールされています：

```text
C:\Users\ユーザー名\AppData\Local\Google\Chrome\User Data\Default\Extensions\ophjlpahpchlmihnnnihgmmeilfjmjjc\バージョン番号
```
* `ユーザー名` の部分は、ご自身のWindowsサインインユーザー名に置き換えてください。
* `ophjlpahpchlmihnnnihgmmeilfjmjjc` は公式LINE拡張機能のIDです。
* `バージョン番号` は、例えば `3.7.3_0` のようなフォルダ名です。LINEの自動アップデートによって数値が変わるため、実際にフォルダの中を確認して最新のバージョンフォルダの名前を指定してください。
  * **ヒント**：エクスプローラーのアドレスバーに `C:\Users\ユーザー名\AppData\Local\Google\Chrome\User Data\Default\Extensions\ophjlpahpchlmihnnnihgmmeilfjmjjc`（`ユーザー名`は書き換える）を貼り付けて開くと、中にバージョン名のフォルダが入っています。

### ステップ 3：パッチを実行して改善版を作成する
1. **ステップ 1** で解凍した本プロジェクトのフォルダ（`Accessible_LINE`）をエクスプローラーで開きます。
2. フォルダ内の何も無い場所で `Shift` キーを押しながら右クリック（またはアプリケーションキー / `Shift + F10` を押す）し、**「ターミナルで開く」** または **「PowerShell ウィンドウをここに開く」** を選択します。
3. 以下のコマンドを入力して実行します（最後の引数には、**ステップ 2** でコピーした公式フォルダのフルパスをダブルクォーテーション `"` で囲って貼り付けてください）：

```powershell
node auto-patcher.js "公式フォルダのパス"
```

**実行例：**
```powershell
node auto-patcher.js "C:\Users\takeru\AppData\Local\Google\Chrome\User Data\Default\Extensions\ophjlpahpchlmihnnnihgmmeilfjmjjc\3.7.3_0"
```

実行が完了し、画面に `SUCCESS! Standalone Accessible LINE Extension has been updated and patched successfully!` と表示されれば、パッチの適用は完了です。本プロジェクトフォルダ自体が「アクセシビリティ改善版のLINE拡張機能」に生まれ変わります。

### ステップ 4：Chromeに改善版LINEを読み込ませる
1. Google Chromeを開き、アドレスバーに `chrome://extensions/` と入力して `Enter` キーを押し、拡張機能管理画面を開きます。
2. 画面右上にある **「デベロッパー モード」のスイッチを「オン」** にします。
3. すでにインストールされている公式の「**LINE**」拡張機能を探し、**「オフ」（無効化）** にします（競合を防ぎ、挙動を安定させるためです。アンインストールしなくても、スイッチをオフにするだけで大丈夫です）。
4. 画面左上にある **「パッケージ化されていない拡張機能を読み込む」**（英語環境では `Load unpacked`）ボタンを押します。
5. フォルダの選択画面が開くので、**ステップ 3 でパッチを当てたこのフォルダ（本プロジェクトフォルダ）を選択**して「フォルダの選択」ボタンを押します。

これで、Chromeに「**LINE (Accessible)**」が登録され、キーボードとスクリーンリーダーで快適に操作できるようになります！

## 🔄 公式LINEのアップデートがあった時は？
LINE公式がアップデートされ、新機能の追加や不具合修正が入った場合でも、以下の手順で簡単にアクセシビリティパッチを当て直すことができます。

1. Chromeで自動的に新しい公式バージョンがインストールされます。
2. **ステップ 2** と同様に、新しいバージョン用のフォルダパス（例：`3.7.4_0` など）を確認します。
3. 本プロジェクトフォルダ（`Accessible_LINE`）でPowerShellを開き、再び `node auto-patcher.js "新しい公式フォルダのパス"` を実行します。
4. パッチ実行後、Chromeの拡張機能管理画面（`chrome://extensions/`）を開き、「LINE (Accessible)」の項目にある **「更新」（または「再読み込み」）ボタン** をクリックするか、キーボードで選択して実行します。

これだけで、最新の公式アップデートを取り込んだ状態で、アクセシビリティ機能を維持し続けることができます。
