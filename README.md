# LINE Chrome拡張機能 アクセシビリティ改善パッチ

このプロジェクトは、Google Chrome版のLINE拡張機能において、**「キーボードでまともに操作できない問題」**および**「トーク履歴の読み上げ順序が逆になる問題」**を一撃で修正するためのパッチスクリプトです。

全盲や弱視など、スクリーンリーダー（音声読み上げ）やキーボード操作を必要とする方向けに作成されています。

---

## 🌟 改善されること
1. **キーボード完全操作対応**：
   友だち一覧・トーク一覧の切り替えタブ、各トークルームの項目、ボタンなどにTabキーでフォーカスが当たり、EnterキーやSpaceキーで確実に実行（クリック）できるようになります。
2. **トーク履歴の時系列読み上げ**：
   トークルーム内のメッセージが、古いものから新しいものへと時系列順に正しく並べ替えられます。スクリーンリーダーで上から下へ順に読むだけで、会話の流れが理解できます。
3. **爆速見出し（Heading）ジャンプ対応**：
   * **トークルームのタイトル** ➔ 見出しレベル1 (`h1`)
   * **メッセージ履歴の各発言** ➔ 見出しレベル2 (`h2`)
   に設定されます。スクリーンリーダーの「H」キー（見出し移動）や「2」キーを押すだけで、読みたいメッセージへ爆速でジャンプできます。

---

## 🛠️ 前提条件
実行するパソコンに **Node.js** がインストールされている必要があります。
インストールされていない場合は、[Node.js 公式サイト](https://nodejs.org/) から推奨版をダウンロードしてインストールしてください。

---

## 🚀 使い方（簡単4ステップ）

### ステップ 1：このパッチをダウンロードする
1. このGitHubページの右上にある「**Code**」ボタン（スクリーンリーダーでは「Codeメニューボタン」）を押します。
2. メニューから「**Download ZIP**」を選択してダウンロードします。
3. ダウンロードした ZIP ファイルを、パソコンの好きな場所（デスクトップなど）に解凍（展開）します。

### ステップ 2：公式LINE拡張機能のインストール先パスをコピーする
お使いのパソコンにインストールされている公式LINE拡張機能のフォルダパスをコピーします。
通常、Windows環境では以下の場所にあります（`ユーザー名`の部分はご自身のパソコンのユーザー名に置き換えてください）：

```text
C:\Users\ユーザー名\AppData\Local\Google\Chrome\User Data\Default\Extensions\ophjlpahpchlmihnnnihgmmeilfjmjjc\3.7.2_0
```
※ 最後の `3.7.2_0` の部分は、LINEのバージョンアップによって数値が変わることがあります。

### ステップ 3：パッチを適用する
1. **ステップ 1** で解凍したフォルダを開きます。
2. フォルダ内の何もない場所で Shiftキー を押しながら右クリックし、「**ターミナルで開く**」または「**PowerShell ウィンドウをここに開く**」を選択します。
3. 以下のコマンドを実行します（最後の引数には、**ステップ 2** でコピーした公式フォルダのパスをダブルクォーテーションで囲って指定してください）：

```powershell
node auto-patcher.js "公式フォルダのパス"
```

**実行例：**
```powershell
node auto-patcher.js "C:\Users\takeru\AppData\Local\Google\Chrome\User Data\Default\Extensions\ophjlpahpchlmihnnnihgmmeilfjmjjc\3.7.2_0"
```

コマンドの実行が成功すると、このフォルダ内のファイルが自動的に書き換えられ、アクセシビリティ改善版の拡張機能が完成します！

### ステップ 4：Chromeに読み込ませる
1. Google Chromeを開き、アドレスバーに `chrome://extensions/` と入力してEnterキーを押します（拡張機能の管理画面が開きます）。
2. 画面右上にある**「デベロッパー モード」のスイッチを「オン」**にします。
3. 今まで使っていた公式の「**LINE**」拡張機能を**「オフ」（無効化）**にします（競合を防ぐためです）。
4. 画面左上にある**「パッケージ化されていない拡張機能を読み込む」**（Load unpacked）ボタンを押します。
5. フォルダ選択画面が出るので、**ステップ 3 でパッチを当てたこのフォルダ（解凍したフォルダ）を選択**して読み込みます。

これで、画面に「**LINE (Accessible)**」が追加され、キーボードと音声読み上げで快適に使えるようになります！

---

## 🔄 公式アップデートが来た時は？
LINE公式にアップデートが入った場合も、新しい公式フォルダのパスを指定して **ステップ 3** のコマンド（`node auto-patcher.js "新しい公式パス"`）を再度実行し、Chromeで「再読み込み」を押すだけで、最新版にアクセシビリティパッチを自動適用して使い続けることができます。
